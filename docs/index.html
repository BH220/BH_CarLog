내 차의 기록을 한곳에

주유, 유지보수, 소모품, 가게 정보를 차량별로 기록하고 연비까지 바로 봅니다. 모든 데이터는 서버 API를 거쳐 오가며, 현장에서 휴대폰으로 남긴 기록은 PC에서 정리합니다.

PC 1.0.0 Windows 10 / 11 (64비트) 게시자 BH Soft
Windows용 설치하기설치 관리자 설치 관리자는 필요한 .NET 런타임을 함께 설치합니다. 휴대폰은 별도 앱 없이 브라우저로 등록합니다(아래 설치 방법 참고).

무엇을 기록하나

영수증과 수첩에 흩어지던 차 관련 지출과 정비 내역을 한 프로그램에서 찾고, 고치고, 되돌아봅니다.

주유

주유일, 주행거리, 금액, 리터당 금액을 적으면 주유량과 직전 주유 대비 연비를 계산해 보여줍니다. 영수증 사진도 함께 붙입니다.

유지보수

정비, 구매, 세차, 공기압 기록을 가게와 함께 남깁니다. 정비 전후 사진과 영수증을 첨부해 두면 나중에 그대로 꺼내 봅니다.

소모품

엔진오일처럼 주기로 관리할 항목을 기간이나 거리로 등록하고, 교체이력(F1)으로 실제 교체한 유지보수 기록과 이어 둡니다.

차량 · 가게

여러 대의 차를 등록해 상단에서 골라 보고, 자주 가는 주유소·정비소·용품점을 가게 목록으로 관리합니다.

새 메시지 (휴대폰 바로등록)

주유소나 정비소에서 휴대폰으로 남긴 기록이 새 메시지로 들어옵니다. 사진을 확인하며 주유·유지보수 실데이터로 전환하거나 버립니다.

잠금과 세션 보호

자리를 비우면 화면이 자동으로 잠기고, 다른 곳에서 같은 계정으로 로그인하면 기존 세션을 확인한 뒤 넘겨받습니다. 앱은 DB에 직접 붙지 않고 인증된 서버 API만 사용합니다.

설치 방법

처음 한 번만 확인하면 됩니다.

1. Windows에 설치

  1. Windows용 설치하기를 눌러 install.exe.zip을 받고 압축을 풉니다.
  2. install.exe를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
  3. 설치가 끝나면 바탕 화면이나 시작 메뉴의 BH Car Logs를 실행합니다.

2. 서버 주소와 로그인

처음 실행하면 로그인 화면이 열립니다. 오른쪽 아래 ⚙에서 관리자에게 받은 서버 주소를 넣고 연결 테스트로 확인한 뒤 저장하세요. 다른 기기에서 이미 로그인 중이면 확인을 거쳐 이 PC로 세션을 옮깁니다.

로그인 뒤 등록된 차가 없으면 차량 화면이 먼저 열립니다. 차를 한 대 등록하면 상단에서 그 차를 고른 상태로 주유·유지보수·소모품을 기록합니다.

3. 휴대폰 바로등록

  1. 관리자에게 차량별 바로등록 주소(/direct/carlog/…)를 받습니다. 주소에 실린 토큰이 차를 정하므로 차마다 주소가 다릅니다.
  2. 휴대폰 브라우저로 열고 홈 화면에 추가해 둡니다. 로그인 없이 주행거리, 기록 유형, 메모, 사진(최대 4장)을 그 자리에서 보냅니다.
  3. PC의 새 메시지 화면에서 들어온 기록을 확인하고 실데이터 전환(F1)으로 주유 또는 유지보수 기록으로 옮깁니다. 가게와 금액은 이때 채웁니다.
